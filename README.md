# Agenda-Rec
Agenda-Rec: an address book that saves contacts as Delphi records in compressed files



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Detailed contact sheet (record): name, dates, relatives, addresses, work, phones, accounts, internet, school
* One compressed `.pk` file per contact, in the `Contacts` folder
* Contact list, add, edit and delete contacts
* Alarm: the contacts' birthdays
* Options: user interface language (from the `Language` folder)
